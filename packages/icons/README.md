# @mp-front/icons

Librería de iconos SVG basados en Font Awesome.

## Instalación

```bash
npm install @mp-front/icons
```

## Uso

```tsx
import { AlarmClock, ArrowRight } from '@mp-front/icons';

function App() {
  return (
    <div>
      <AlarmClock />
      <ArrowRight />
    </div>
  );
}
```
